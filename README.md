# Darkline × Fiesta

An event website built solo for **Darkline × Fiesta** — a real, one-night event in Nairobi combining a football tournament (Footwork Fiesta) and a rooftop afterparty (Darkline Party). Built from concept to live deployment for an actual event with real ticket sales, not a class assignment.

**Live site:** https://darklinexfiesta.netlify.app/
**Repo:** https://github.com/lennymethu-sys/DarklineApp

## Overview

Unlike my school projects, this was built for a real event with a real deadline and real attendees — which meant no room for half-finished features. I designed and built the entire site solo: layout, styling, ticket-tier display, and interactive elements, end to end but unfortunately it's not in use due to some unknown reasons.

## Features

- **Event landing page** with countdown-style event details (date, venue, "one night only" framing)
- **Multiple ticket tiers** (Spectator, Regular, VIP, Full Pack) each with live remaining-spots tracking
- **Team page** showcasing event organizers with an interactive "tap to learn more" bio reveal
- **About / Contact pages** telling the story behind the two brands (Darkline Party + Footwork Fiesta)
- **Admin/Team portal login** for internal event management

## Tech Stack

- HTML, CSS, and vanilla JavaScript
- Deployed on Netlify

## Getting Started

```bash
git clone https://github.com/lennymethu-sys/DarklineApp.git
cd DarklineApp
```

No build step or dependencies required — open `index.html` directly in a browser, or serve the folder with any static server:

```bash
npx serve .
```
